# DSA Solutions

Automated archive for my accepted competitive-programming solutions from LeetCode, CodeChef, and HackerRank.

## Structure

```text
DSA-Solutions/
├── LeetCode/
├── CodeChef/
└── HackerRank/
```

Each imported solution will keep its platform, problem, language, difficulty, and useful metadata where the platform exposes it.

The sync workflow will be added once platform authentication is configured in GitHub Actions Secrets.
